¿Cuál es el punto más débil de PGP?

La gestión de claves y el factor humano. Su modelo de confianza es demasiado complejo para el usuario promedio, lo que genera errores de configuración. Además, PGP cifra el contenido del mensaje, pero deja completamente expuestos sus metadatos (remitente, destinatario, fecha y asunto).

¿Cuándo es conveniente utilizar solamente cifrado simétrico?

Cuando se protegen datos en reposo y no es necesario compartir la clave con terceros a través de internet.

Discos duros locales: Utilizando herramientas como BitLocker o FileVault.

Copias de seguridad internas: Para almacenar registros de bases de datos.

Datos masivos: Es computacionalmente más rápido y ligero que el cifrado asimétrico.

¿En qué consiste el ciclo de vida del desarrollo de software seguro (SSDLC)?

¿Qué ocurre en Requisitos? Se identifican las normativas aplicables (ej. GDPR) y se definen los controles de seguridad obligatorios.

¿Qué se hace en el Diseño? Se realiza el Modelado de Amenazas para anticipar vulnerabilidades desde la arquitectura del sistema.

¿Cómo se aplica en el Desarrollo? Se programa siguiendo buenas prácticas y se analiza el código fuente con escáneres automáticos (SAST).

¿Qué pasa en las Pruebas? Se ataca la aplicación ya compilada con análisis dinámicos (DAST) y pruebas de penetración manuales (Pentesting).

¿Qué se hace en el Despliegue? Se fortifica el entorno de producción (Hardening), asegurando servidores y bases de datos.

¿Cómo se gestiona el Mantenimiento? Se monitorean ataques en tiempo real y se aplican parches a nuevas vulnerabilidades.
